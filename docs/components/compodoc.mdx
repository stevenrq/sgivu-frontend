# Compodoc

sgivu-frontend incluye [Compodoc](https://compodoc.app/) para generar documentación técnica automática a partir de los JSDoc del código fuente. Es el complemento a esta documentación Mintlify: mientras esta guía explica el "por qué" y los patrones, Compodoc ofrece la referencia detallada de cada clase, servicio, componente y ruta.

## Levantar Compodoc Localmente

```bash
npm run docs:serve
```

Genera la documentación y la sirve en **http://localhost:8080** con hot-reload.

Para solo generar los archivos sin servirlos:

```bash
npm run docs
```

La salida se genera en `compodoc/` (en la raíz del repo, gitignoreada — es un artefacto generado, no se versiona).

<Note>
  La salida de Compodoc se genera **fuera** de `docs/` a propósito: sus web
  components (`compodoc-menu`) entran en conflicto con el runtime de Mintlify si
  conviven dentro de la raíz de contenido, rompiendo el preview local de la
  documentación.
</Note>

## Configuración

La configuración de Compodoc está en `tsconfig.doc.json`:

```json
{
  "extends": "./tsconfig.json",
  "include": ["src/**/*.ts"],
  "exclude": ["src/**/*.spec.ts", "src/test-setup.ts"]
}
```

Incluye todos los archivos TypeScript de `src/` excepto los tests.
